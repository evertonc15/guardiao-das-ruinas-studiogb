
# Guardião das Ruínas: Ecos do Vazio

## Breve Descrição

Guardião das Ruínas: Ecos do Vazio é a continuação de Guardião das Ruínas.

Após reunir os Fragmentos de Energia e abrir a passagem das antigas ruínas,
o Prisioneiro descobre uma região subterrânea afetada por uma energia
desconhecida.

Para impedir que essa energia destrua o local, o jogador deverá atravessar
as Ruínas, investigar o Buraco Negro e alcançar a Sala Principal.

Durante a jornada, será necessário enfrentar robôs, superar plataformas
e utilizar diferentes tipos de ataque.

## Plataforma

StudioGB / Game Boy Color
